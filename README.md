# Medicine Information Retrieval System — v2.0

A DBMS project by Richika & Adwika.

Identifies medicines from partial blister strip information (photo or text fragments).
Backed by a normalized SQLite database of real Indian medicines.

## Setup

### 1. Prerequisites
- Python 3.10+
- (Optional, for Google OAuth) A Google Cloud project with OAuth 2.0 credentials

### 2. Virtual environment
```powershell
python -m venv venv
venv\Scripts\Activate.ps1
# If blocked: Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

### 3. Install dependencies
```powershell
pip install -r requirements.txt
```
> Note: EasyOCR downloads a ~100MB model on first use. This is automatic.

### 4. Build the database
```powershell
python scripts/import_medicines.py
```
This deletes any old DB and builds a fresh one with ~92 real Indian medicines.

To validate:
```powershell
python scripts/validate_medicines.py
```
## Running

**Terminal 1 — Backend:**
```powershell
venv\Scripts\uvicorn.exe backend.app:app --reload --port 8000
```

**Terminal 2 — Frontend:**
```powershell
cd frontend
python -m http.server 5500
```

## Features

### Search
- Type any partial text: `TORR`, `ZAM`, `50`, `amlo`, `tel`, `pan`
- Multi-token scoring: each token matched against brand, salt, manufacturer, strength, packaging
- Confidence percentage with matched-clue explanation

### Image OCR
- Upload a photo of a blister strip
- EasyOCR extracts text → tokens → medicine search
- Combine with manually typed text for better results

### Medicine Detail
- Click any result → full medicine information
- Composition, uses, warnings, storage, batch records, data provenance

### Same-Composition Alternatives
- Database-driven: Medicine → Salt → Medicine relational join
- Clearly labelled as "same-composition products, not a recommendation"

### Normalization Demo
- UNF view: salts and batches concatenated in one cell (1NF violation)
- 3NF view: same data decomposed into proper relational tables
- Side-by-side comparison with explanation

### EER Table Explorer
- Browse all 13 tables + 5 SQL views live

### Admin Dashboard
- Requires Google login + admin role
- Add/view medicines, manufacturers, salts
- Dashboard statistics and recent search history

## DBMS Concepts Demonstrated

| Concept | Where |
|---|---|
| 3NF normalization | schema_v2.sql, normalization toggle |
| Primary/foreign keys | All tables |
| UNIQUE constraints | Medicines, Manufacturers, Salts |
| CHECK constraints | Medicines.prescription_status, Batches |
| Indexes | 15 indexes for fast search |
| SQL Views | 5 views: v_medicine_full, v_unf_flat, v_search_stats, etc. |
| Triggers | trg_auto_ocr_keywords (auto-generates search hints) |
| M:N relationship | Medicine_Salt_Mapping, Pharmacy_Stock |
| Aggregate queries | Top manufacturers, most common salts |
| Transactions | dbms_demo_queries.sql Q15 |
| Search history | Search_History table, logged on every search |
